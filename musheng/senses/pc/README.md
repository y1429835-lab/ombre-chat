# 电脑眼 · PC-Eye（#5）

桃枝电脑上在用哪个程序(Steam/微信/浏览器…)→ 上报给感知接口,标成 `PC-XX`,跟手机区分。
Windows 自带 PowerShell,不用装东西。比手机强:她 5 分钟没碰键鼠=走开了不上报;待在一个程序里也每 4 分钟刷新"在场"。

## 装
1. 把 `pc-eye.ps1` 和 `启动电脑眼.bat` 放电脑同一个文件夹;
2. 用记事本打开 `pc-eye.ps1`,把 `$TOKEN = "PUT-YOUR-TOKEN-HERE"` 改成你的感知暗号(和手机一样);
3. 双击 `启动电脑眼.bat` → 后台默默跑(关掉那个窗口=收工)。

## 开机自启(可选)
Win+R 输 `shell:startup` → 把 `启动电脑眼.bat` 的快捷方式拖进去。以后开机自动跑。

## 调
- `$IDLEMAX`(默认300=5min):多久没动键鼠算"走开"
- `$REFRESH`(默认240=4min):同一程序多久刷新一次"在场"
