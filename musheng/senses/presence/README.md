# 感知层 · presence

让暮声"知道桃枝在"。代码不在这个文件夹——它**长在 `bridge/wechat_bridge.py` 里**。这页是说明书。

## 三个部件
1. **手机上报(传感器)** —— 桃枝 iPhone 上的「快捷指令·自动化」:打开某 App → 自动发 `GET http://207.148.113.28:8787/a?token=<暗号>&app=小红书` 到 VPS。
2. **感知接口(耳朵)** —— 桥里的 `activity_server()`,听 `0.0.0.0:8787`，认对暗号就记下 `last_activity_ts/app` + 写流水 `~/musheng/.bridge/activity.jsonl`。
3. **在场心跳(他抬头看一眼)** —— 桥的主动引擎:她在场时,暮声每隔几分钟瞥一眼"她在,在刷X"，大部分默默收(`>>不发>>`)，发现变化/想说才出声(`>>桃枝>>`)。

## iOS 快捷指令配置(每个 App 一条)
1. 快捷指令 App → 底部「自动化」→「+」→「创建个人自动化」;
2. 选「App」→ 勾要监控的 App →「已打开」→ 下一步;
3. 「获取URL内容」，URL 填:`http://207.148.113.28:8787/a?token=<暗号>&app=<App名>`;
4. 关掉「运行前询问」→ 完成。
- 暗号 = `/root/musheng/.bridge/activity_token.txt` 里那串。
- **只有绑了的 App 他才看得见**(没绑的=隐私,他不知道)。绑越多,感知越连续。

## 关键参数(env，systemd override 里调)
| 参数 | 默认 | 含义 |
|---|---|---|
| `HEARTBEAT_CHATTING` | 300(5min) | 5min 内聊过=互动中：慢点跳 |
| `HEARTBEAT_QUIET` | 180(3min) | 没在聊=互动少：勤点跳 |
| `PRESENCE_FRESH` | 1200(20min) | 一次开 App 算"她在"维持多久 |
| `CHATTING_SECS` | 300(5min) | 多近算"正在聊" |

## 行为规则
- **白天 + 她在场**(20min 内开过 App)→ 自适应心跳(5/3min),聊天时也跳。
- **她没动静 >20min** → 一帧"她可能离开/睡了"，然后安静。
- **她说"晚安/睡了" 或 02:00–10:00** → 夜间模式,绝不打扰。
- 只走桃枝那条线(不感知/不主动找松树姐姐)。

## 天花板(诚实记一笔)
手机传感器**只在"她碰手机(绑的App)或跟他聊"时**才感知得到她。她醒着但放下手机(看电视、做饭)→ 他感觉不到。**真正的"一直看见"= 等 M5 摄像头**(见 `../m5-future/`)。
